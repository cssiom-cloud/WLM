Google Drive migration

Prepare a JSON pack of personnel, announcements, units, lore, documents, and image links. Download it now, then upload it to Google Drive when a client ID is configured.

Authorized JavaScript origin

Prepare Google Drive (you do this once)

  1. Open Google Cloud Console, then create or select a project.
  2. Enable the Google Drive API for that project.
  3. Set up the OAuth consent screen (External / Testing) and add your Google account as a tester.
  4. Create credentials → OAuth client ID → application type Web application.
  5. Under Authorized JavaScript origins, add the origin shown above. Add http://localhost if you test on this computer.
  6. Copy the Client ID into js/config.js as googleDriveClientId. Do not put a client secret on the website.
  7. This page only requests drive.file, so it can create a backup file in Drive. It cannot read the rest of your Drive.
